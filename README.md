# App隐私整改核验

通报发布后的十五个工作日倒计时内，本产品把"改了隐私政策文字"和"同一客户端版本上权限弹窗、实际采集、账号注销全部生效"区分开来：App 与小程序按渠道登记版本与个人信息规则，检测会话在具体版本上重现违规条件，审查结论与期限事件按发生时间留痕，报送监管的结论始终可以从原始检测记录重建。

## 数据流

```
检测规则+样例调用 ──► 规则来源（版本化，样例全通过才生效）
                        │
版本登记（渠道） ──► 版本登记簿 ──► 检测会话 ──► 检测发现（只增不改）
                                        │
通报/顺延/节假日 ──► 期限时间线           ├─► 审查结论合并（多人一致）
                                        │
                                        ▼
                              报送结论（原始记录确定性重建）
```

1. **规则来源**（`fixtures/ruleset.json`，合同 `contracts/ruleset.schema.json`）：检测规则以声明式条件描述违规，每条规则附带样例调用与期望结论；规则集加载时逐条执行样例，任一不符即拒绝，规则行为可回归。检测会话与报送结论都引用规则版本及其内容摘要。
2. **版本登记**（`fixtures/releases.json`）：App 与小程序按 `应用/平台/渠道/版本/构建号` 登记个人信息规则版本、权限用途、采集字段、第三方组件与注销路径。生效一律按发生时间：
   - **全量发布** 自 `effective_from` 生效；`submitted_at`/`approved_at` 记录商店提交与审核通过，审核延迟期间旧版本仍生效；
   - **灰度发布** 对灰度人群自 `effective_from` 生效，对全量人群自 `full_rollout_at` 生效，检测时需声明设备是否在灰度人群；
   - **小程序热更新** 以推送时间即时生效，无需商店审核。
3. **检测会话**（`fixtures/sessions.json`）：记录发生时间、环境、针对每条规则的观测与证据，系统按规则版本推导"命中/未命中"。每条失败发现携带重现条件（环境与观测），例如"非必要权限被拒绝后核心功能不可用"。
4. **审查结论**（`fixtures/verdicts.json`）：多名审查员对同一对象分别判断；一致即采纳，分歧由负责人裁决，仍不一致则保持争议。合并是判断集合的纯函数，与提交顺序无关。
5. **期限事件**（`fixtures/events.json`）：整改期限自通报次日起数工作日，跳过周末与节假日；法定期限顺延以事件发生时间重放，例如样例中通报日 2026-06-01（周一）、端午 2026-06-19，基准期限为 2026-06-23，6-22 发生的 5 个工作日顺延将期限推至 2026-06-30。
6. **报送结论**：由原始登记、会话、审查与事件记录确定性重建（`build_report`），不读时钟、不依赖登记顺序；报告含 `inputs_digest` 与 `report_id`，监管方持同一批原始记录调用 `verify_report` 即可复算。

## 一致性规则

- **重复提交幂等**：同一版本、同一会话、同一结论重复提交（仅到达时间不同）只形成一条记录，以内容摘要判定。
- **内容冲突拒绝**：同一标识提交不同材料抛出 `ConflictError`，早先事实不能被后一次提交改写。
- **失败不可覆盖**：检测发现只增不改；后一次复测通过会成为"当前结论"，但早先失败连同其版本、时间与重现条件完整保留在历史中。
- **按发生时间排序**：灰度、审核延迟、热更新、顺延全部以事件发生时间参与判定，与登记先后无关。

## 数据最小化

证据登记前必须经最小化策略处理（`src/minimize.py`）：系统版本、客户端版本等环境字段原样保留；设备号、账号等标识符加盐哈希；精确位置、通讯录、自由文本备注等一律丢弃。留存清单（保留/哈希/丢弃字段及原始内容摘要）随证据保存，未最小化的证据在登记时即被拒绝。

## 本地校验

```bash
python3 -m unittest discover -s tests -t .
```

88 个用例覆盖：合同校验、规则样例回归、版本幂等与冲突、灰度/审核延迟/热更新生效、失败历史不被覆盖、审查合并与顺序无关、期限顺延重放、证据最小化拦截、报送结论重建与篡改检出。

## 领域资料

`contracts/*.schema.json` 定义共享资料格式，`fixtures/*.json` 提供可公开使用的虚构样例（`sessions.json` 由 `scripts/gen_sessions.py` 经真实最小化逻辑生成，证据摘要可复算），不含真实个人信息、账号、密钥或连接凭据。
